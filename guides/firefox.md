# Hermes Browser Extension on Firefox

Firefox runs the same extension as Chromium, in its own sidebar, with fewer powers. This guide says what works, what is limited and what is unavailable on each surface, why, and what to do instead. Settings > About & Diagnostics shows the Firefox limits inside the extension (**Firefox limits**), so you can read them before you start a task.

Hermes Control is not Chromium-only. Firefox has a restricted Hermes Control: it can read the page, open addresses, scroll, take a screenshot you allow, and list, open, switch and close tabs. It cannot click, type or press keys, because that needs trusted input, which Firefox gives an extension no way to send. That is the one large gap; the tables below list the rest.

Written against Firefox 159.0.1 on Windows and the extension at v0.4.0.

## How to read the tables

| Status | Meaning |
| --- | --- |
| Supported | Works the way it does on Chromium, or as described. |
| Limited | Works with a stated restriction. |
| Experimental | Built, but not shown to work in Firefox yet. Expect to need the fallback. |
| Unavailable | Not there. The fallback column says what to do. |

**Decided by** says what sets the limit: the browser's own API (`Browser API`), a permission you can grant (`Permission`), your Hermes gateway (`Gateway`), the connection to it (`Transport`), something this extension does not offer, whether retired or not built yet (`Not offered by the extension`), or nothing but the extension's own code (`Extension code`).

A dagger (†) marks a Firefox cell that has not been run in Firefox: it is the same code that runs on Chromium, so the status is what the code supports, not something anyone has watched happen. A cell without a dagger was read from the manifest, the Firefox build profile, the code and its tests.

Beyond reading the code, these were run in a real browser while writing this guide (Chrome for Testing, and Firefox 159.0.1 with a temporary install of the Firefox build): which shortcuts each browser registers, that Firefox has no `debugger`, `offscreen`, `sidePanel` or browser speech recognition API, that every right-click menu context is accepted and nests under the Hermes entry, and that Hermes Assist's draft host appears next to a focused field on a page. Nothing here was run against a Hermes gateway on Firefox.

The tables below are generated from `extension/lib/browser-capability-matrix.mjs` (`npm run sync:capabilities`). A test fails if they drift from it, and other tests pin each row to the manifest, the Firefox build profile or the code that decides it.

## Hermes Control on Firefox

Hermes Control is opt-in and works only in tabs you attach. On Firefox the same rules apply as on Chromium: tab scope, approval for risky actions, restricted pages and blocked sensitive fields. Nothing is relaxed to make up for a missing API.

What Hermes can do in an attached Firefox tab: read the page text and its list of controls (`tab_snapshot`), open an address (`tab_navigate`), go back (`tab_back`), scroll (`tab_scroll`), take a screenshot (`tab_screenshot`, after **Allow screenshots on Firefox**), and list, open, switch to and close tabs (`tab_list`, `tab_create`, `tab_activate`, `tab_close`).

What it cannot do: click, type, fill, select, press keys, hover, drag, scroll to an element, group tabs or run batches. Hermes does not imitate trusted input with page events, so those actions are not offered rather than faked. When a chat asks for one anyway, the answer names the actions this browser does offer, so Hermes can switch to one of them or ask you to do the step. Hermes Control itself also needs a Hermes with Hermes Control: built in on Hermes 0.22.5 and earlier, the extension's Hermes plugin on current Hermes (see [companion-plugin/README.md](../companion-plugin/README.md)).

## Hermes Web on Firefox

Hermes Web is the Webapp your own gateway serves, opened in a normal browser tab by the panel. The extension's own full-page chat view was retired in both browsers; the sidebar (Firefox) and the side panel (Chromium) are the supported chat surfaces.

## Shortcuts

Alt+H runs the toolbar button on both browsers. Ctrl+Shift+H (Command+Shift+H on macOS) opens the sidebar and exists only on Firefox: Chromium has no sidebar command, so it registers nothing there. Firefox lets you change either on `about:addons`, under the gear menu, **Manage Extension Shortcuts**.

## Not covered

Not audited in this guide, and so not in the tables: Bot Mode group rooms, Projects, theme marketplace downloads and page comments. They use no Chromium-only API that was found, but nobody has run them in the Firefox sidebar. File an issue with your Firefox version, Windows version and extension build from **Copy Diagnostics** if one fails.
