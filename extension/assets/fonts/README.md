# Bundled fonts

## Rules (Blaze Type)

The `Rules*.woff2` files are **Rules** typefaces by [Blaze Type](https://blazetype.eu/), shipped in this repository under **Nous Research's commercial license** for the Hermes Browser Extension signature profile. They are not redistributable outside this project except as permitted by that license.

## Other bundled faces

- **Sigurd** (`Sigurd-Variable.woff2`) and **Collapse** — bundled display fallbacks when a signature `@font-face` fails to load.
- **`google/`** — SIL Open Font License subsets (see each `*-OFL.txt` file).
- **JetBrains Mono**, **Courier Prime** — bundled monospace faces.
